# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。

# 重叠反例

overlap.csv中E100原班次10月1日22点进、10月2日06点出，排班调整补录10月2日00点至08点新版本班次，两班在00:00–02:00、03:00–04:00、04:30–06:00重叠共270分钟。若分别核算，这270分钟进入两次工资；裁决后归新版本班次，原班次只保留22:00–24:00与04:00–04:30共150分钟，扣回证据逐段写明两条班次。E101两班同版本，05:00–06:00重叠60分钟归实际到岗更早的原班次。E102无重叠作对照。全表原始1920分钟=可付1590分钟+扣回330分钟，应发770元、实发720元、差额50元。
